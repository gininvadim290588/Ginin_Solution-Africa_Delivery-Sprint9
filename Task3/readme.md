## Assumptions

**AS-01:** ограниченный пилот — 100 продавцов/5 000 SKU, 2 000 заказов/мес суммарно, AOV $25; это гипотеза T2, не миллион покупателей А2. **AS-02:** нагрузочная граница на страну: каталог 100 RPS 30 мин, 300 RPS 5 мин; платёжные намерения 5/10 RPS; события уведомлений 10/20 в секунду. Прогноз не выведен из 10M регистраций; проверяется тестом до live.

**AS-03:** оценки расходов из T2, $5K/FTE/мес fully loaded; оферт и статистики отказов нет. Ротация инженеров обеспечивает on-call, не круглосуточный центр с постоянной сменой. **AS-04:** каждая страна может предоставить законные независимые домены отказа, резервное хранилище и вторую площадку; иначе RTO/RPO и SLO не подтверждены.

**AS-05:** приложение В среди доступных вложений не найдено. Используем стандартные шесть полей QAS: источник, стимул, среда, объект, реакция, мера реакции. Шаблон Б FMEA сохранён по структуре. **AS-06:** договорные возможности PSP/шлюзов — неизвестны; целевые партнёрские SLO нельзя выдавать за их SLA. Политика страны для PII/копий/телеметрии из V2 — предосторожность до юридического заключения, не утверждение о тексте закона.

**AS-07:** дедлайны встречи 12.10 и go/no-go 14.10 сохранены из Task2. НФТ не устраняют календарный риск: готовность полного greenfield-MVP к 15.10 не доказана. Без подписанного исключения инвестора из 99,99%/RPO=0/запрета деградации — no-go.
