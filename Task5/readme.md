## Три важных ограничения

1. **Шифрование не разрешает вывоз.** Резервная копия, логи, ключи и удалённый доступ также проверяются.
2. **Купленные номера не доказывают согласие.** Рекламная база 410 000 контактов заблокирована до проверки основания; обычное оформление заказа не требует подписки на рекламу.
3. **Восстановление каталога за час не означает безопасную оплату за час.** При потерянных записях финансовые операции ограничены до сверки. Два города одного поставщика сохраняют риск общего отключения.

## Короткий словарь

**NG / KE / ZA** — Нигерия / Кения / ЮАР. **БД** — база данных. **PSP** — платёжный провайдер. **SLA** — договорная гарантия качества; **SLO** — измеримая цель команды. **RTO** — время восстановления функции; **RPO** — допустимая давность восстановленной точки. **KMS / HSM** — сервис управления ключами / специальное защищённое оборудование для ключей.

## Как открыть и воспроизвести

Для чтения диаграмм достаточно PNG. Для рендера исходников нужен PlantUML с поддержкой ELK; проверено на версии **1.2026.3**, используется `!pragma layout elk`. C4-PlantUML v2.12.0 встроен в `c4-container.puml`, интернет и внешние include не нужны.

Из папки Task4: `java -jar /путь/plantuml.jar -charset UTF-8 -tpng c4-container.puml deployment-diagram.puml`.

В [архиве](africa-delivery-task-4.zip) лежит Task4 и копии документов Task1–3, на которые непосредственно ссылается это задание. В существующем репозитории используйте его собственные соседние папки. Для отдельного скачивания предыдущих документов есть ссылки в обзоре источников.

## Assumptions

- План относится к ограниченному пилоту NG/KE 15.10.2026; ЮАР и расширенные функции позже.
- Договоры, юридический допуск и испытания не считаются выполненными. Список обязательных проверок и владельцы приведены в плане переключения.
- Названные местные поставщики — кандидаты до подтверждения; цена Google и задержки явно помечены как оценки.
