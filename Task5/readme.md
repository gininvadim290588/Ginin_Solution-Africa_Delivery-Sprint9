# Task5 — план запуска и развития Africa Delivery

**Рекомендация:** небольшой маркетплейс с собственным каталогом и заказами, партнёрской оплатой и доставкой. В MVP входят **8 из 29 пунктов Product Manager в сокращённом виде**. Ни один из этих восьми пунктов не обещается в полном исходном объёме.

Начало кейса — **10 августа 2026 года**. Базовый план на восемь недель заканчивается **5 октября**, открытие назначено на **15 октября**: календарный резерв — десять дней. Готовность исполнителей и условий начала работ является допущением; выполнение ещё нужно доказать. **20 августа** — предельный расчётный старт без резерва, а не начало кейса. [Календарь и исходные даты](../case-calendar.md).
