# Ginin_Solution-Africa_Delivery-Sprint9
Крупный инвестор хочет реализовать маркетплейс в одной из стран Африки, то есть на рынке, где подобного ещё нет. Реклама уже запущена. Открытие намечено через два месяца. Средств на реализацию немного, но запуститься нужно точно в срок. При этом даётся полный карт-бланш.Москве, Санкт‑Петербурге, Екатеринбурге и Новосибирске.
